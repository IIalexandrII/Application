MainActivity
    - mSession	    (Session)	Основной объект ARCore для управления отслеживанием и камерой.
    - arcRenderer	(ARCoreRenderer) рендерер для отрисовки графики и детекций.
    - YOLOModel	    (Model) Экземпляр модели нейронной сети для распознавания объектов.
    - conductor     (Conductor)	Экземпляр дирижера

    - onCreate: Настраивает UI, инициализирует рендерер и привязывает слушатели событий к кнопкам загрузки моделей и вызова настроек. (Здесь код для загрузки из assets)
    - setupGlSurfaceView: Устанавливает версию EGL контекста (2.0) и связывает поверхность с arcRenderer.

    - onResume: Если сервисы установлены и разрешения получены, создает/возобновляет сессию, настраивает режим глубины и фокус.
    - onPause / onDestroy: Безопасно приостанавливает сессию и очищает временные файлы моделей для предотвращения утечек памяти.

    - loadExternalModel: Обрабатывает выбор файлов пользователем. Копирует выбранные .pte и .txt файлы во внутренний кэш приложения.
    - showSettingsDialog: Динамически изменяет статические параметры PostProcessor, позволяя пользователю на регулировать чувствительность детекции.

    - copyUriToCache: Утилита для копирования данных из Uri во временный файл (для загрузки файлов из внешнего хранилища).
    - getJsonFromAssets: Десериализация конфигурационных файлов формата JSON в объекты Java с помощью библиотеки Gson.

ARCoreRenderer
    - bufferSize - размер буфера для функции denoise.
    - bufferImages - сам буфер.
    - bufferCurrentSize - текущее значение заполнености буфера.

    -onDrawFrame: (121 строка) если модель не загружена то просто ресует изображение с камеры. 
                  (196 - 212 строки) заполняем буффер и запускаем функцию noiseDetect которая возвращает Bitmap для модели.
                  (176 - 181 строки) запуск дирижера и тестовый вывод на экаран информации.

    - сеттеры:
            setModel(Model model) - вызывается стразу после загрузки модели из файла и создания экземпляра класса в MainActivity.
            setConductor(Conductor conductor) - вызывается стразу после загрузки настроек из файла и создания экземпляра класса в MainActivity.
            setSession(Session session) - вызывается стразу после инита сессии в MainActivity.

Model:
    - Classes: публичное поле массив стрингов содержит классы модели где индекс элемента это id для модели. 
    - Model: Принимает пути к файлам и контекст. Определяет, загружать ли модель из встроенных ресурсов (assets) или из внешней памяти. Инициализирует вспомогательные объекты Canvas и Bitmap для подготовки данных.
    - _loadModel / _loadClasses: Группа приватных методов для чтения бинарных файлов модели и текстовых файлов со списком имен классов.
    - destroy: Принудительно освобождает нативную память, занятую моделью PyTorch.
    - analyzeImage: основной метод для обработки кадра.
